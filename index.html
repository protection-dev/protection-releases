Install Protection

On the phone you want to track, download the app below, then open it and enroll with your pairing code.

Download Protection Using an older 32-bit phone? Download the 32-bit build

Then in the app, choose Tracked phone and enter this pairing code:

  1. Open the downloaded file and tap Install.
  2. If asked, allow installing from this source — a one-time prompt.
  3. Open Protection, choose Tracked phone, and enter the pairing code shown on the other phone.

Only install this on a phone you own or are authorized to manage.
